目标范围：任意网页 / 其他窗口：① 任意网页——主站「▣ 其他网页」可共享任一标签页；装了浏览器扩展后，悬浮球里能直接下拉选择任意已打开的标签页并用 tabCapture 直采，全程没有共享窗口。② 其他应用窗口 / 系统声音——主站「▣ 其他窗口 / 系统」在共享窗口切「整个屏幕」并勾选「同时分享系统音频」即可（Windows + Chrome；macOS 多数版本只给标签页音频）。这类桌面级采集浏览器无法静默授权，但本站只需授权一次就保持连接，之后按 C / F9 直接录；想一次都不弹，把 Windows「立体声混音」或 VB-Cable / BlackHole 等虚拟声卡设为默认输入，再选「◉ 麦克风」即可录下系统全部声音。③ 本站声音——「◎ 本站声音」走内录通道，零弹窗。

不弹共享窗口 / 一次授权长期复用：浏览器安全规则规定，普通网页无法静默读取别的网站或别的窗口，采集外部声音至少要由你选一次来源。本站已改为保持共享连接：第一次授权后音频流不断开，之后按 C 或 F9 直接开录，不再弹窗；状态栏的绿色「● 共享已保持」表示连接仍在。想换音源点「⛔ 断开共享」，或取消勾选「保持授权」。
高级用法：用 Chrome 启动参数 --auto-select-desktop-capture-source=标题 固定共享源，可连第一次共享窗口都省掉；要真正静默采桌面音频则需要原生程序（WASAPI loopback / 系统音频驱动），网页与扩展都做不到。

采样选区编辑：采样库每条右侧「✂ 编辑」打开波形编辑器：拖动框选、拖手柄微调、输入起止时间，可试听选区、归一化、调增益、淡入淡出、反向播放，然后「裁剪并替换」或「另存为新采样」，也能单独下载选区 WAV。替换会同步更新绑定它的轨道。

悬浮采样：右下角圆球可拖动、点击展开。按 B 也能唤出。点「弹出置顶窗」后，采样器会变成始终在屏幕最前的小窗（Chrome / Edge 的画中画），此时切到别的网页、在共享窗口里选择那个标签页并勾选「分享标签页音频」，即可录下它的声音。
采样自动去掉空白并做音量归一化，存在本机浏览器数据库里，可试听、下载 WAV、导入本地音频，或一键绑定到任意轨道当作音色使用（键盘可变调演奏）。

两种悬浮方式：① 零安装（推荐）—— 站内悬浮球 +「弹出置顶窗」，Chrome / Edge 会开一个始终置顶的画中画小窗，切换网页也不会消失；② 一次性安装扩展 —— 悬浮球直接出现在每一个网页上，随手采集当前页面声音，采样下载后导入本站即可当作音色。扩展包在工具台采样库顶部下载。

电脑端采样卡住（一直弹共享窗口）：共享窗口里必须先在左侧列表点选一个标签页、右侧出现预览，再勾选「同时分享标签页中的音频」，最后点「分享」；只勾音频却没选标签页时「分享」按钮不可点，看起来就像反复弹窗。选「窗口 / 整个屏幕」多数系统不给音频轨，此时采样状态栏会写明原因并建议改切麦克风。若置顶窗里始终拿不到声音，点窗内「↩ 回主站采样」回到普通标签页重试（成功率最高），或直接用「导入本地音频」。等待选择期间按钮会变成「⏳ 已弹出共享窗口…」，不会重复弹第二个窗口。

iPhone 采样提示：为绕开静音键，页面平时会把系统音频会话设为「播放」；点「开始采样」时会自动切成「可录可放」并在结束后切回，避免 AudioSession category is not compatible with audio capture。若仍失败，请先关闭其他正在播放或录音的 App（音乐、微信语音、导航等），刷新页面后直接点「开始采样」；也可以改用「导入本地音频」。

电脑端录制器报错：若出现 There was an error starting the MediaRecorder，通常是浏览器把「共享窗口的视频轨 + 音频轨」一起交给了纯音频录制器。本站已改为只取音频轨、编码器自动降级，并在录制器仍不可用时自动切到 Web Audio 直采（状态栏会提示「兼容采集模式」），无需重新授权。若两种模式都失败，多数是共享了「窗口 / 整个屏幕」，请改选正在发声的标签页，或切「麦克风 / 外放」。

移除采样：采样库每条右侧的「✕ 删除」需点两次确认（避免误删）；面板右上「✕ 清空」可一次移除全部，同样需二次确认。删除会同步清掉本机数据库里的音频，并自动解除引用它的轨道绑定（轨道恢复默认音色）。悬浮球与置顶窗的「最近采样」里也能直接删单条。
