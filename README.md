# LOGEN STUDIO

浏览器里的音乐工作站：弹琴、采样、导出，还有个能在别的网页采声音的扩展。

打开网页就能用，不用装环境。

## 在线使用

打开 `https://568kkkkk.github.io/LOGEN-STUDIO/` 就能用。

网页采样需要 HTTPS，GitHub Pages 自带。

## 功能

- **音序器与合成器**：多轨步进音序、键盘演奏、滤波器 / 延迟 / 混响 / 压缩、示波器。
- **导出与分享**：WAV（离线渲染）、MIDI 分轨、工程 JSON 导入导出。
- **采样**：可保存/调用本地采样，绑定到任意轨道变调演奏。
  - 音源：其他网页 / 系统声音、其他窗口 / 系统、本站声音内录、麦克风。
  - 「其他网页」首次授权后保持连接，之后不再弹共享窗口；「本站声音」全程不弹窗。
  - 浏览器扩展可直接采当前标签页或其他已打开标签页，无需共享窗口。
- **采样编辑**：波形选区、试听、归一化、增益、淡入淡出、反向、裁剪替换 / 另存 / 下载。
- **界面**：自定义配色、键盘折叠、手机横屏适配、悬浮球与置顶画中画窗。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `C` / `F9` | 开始 / 停止采样 |
| `V` | 折叠 / 展开键盘 |
| `R` | 开关实时录制 |
| `←` / `→` | 移动 Pattern |
| `B` | 唤出悬浮采样球 |

## 浏览器扩展（可选）

用于「任意网页无弹窗直采」：

1. 下载仓库中的 `logen-extension.zip` 并解压；
2. 打开 `chrome://extensions`，开启「开发者模式」；
3. 点「加载已解压的扩展程序」，选择解压后的 `logen-extension` 目录；
4. 在任意网页点右下角悬浮球，选择音源后按 `F9` 采样。

需要 Chrome / Edge（MV3）。若浏览器要求「用户调用扩展」，点一下工具栏的 LOGEN 图标即可。

## 说明

直接双击 `index.html` 就能打开，但采样需要 HTTPS 或 localhost 环境，这种情况用上面的线上地址最省事。

浏览器安全规则不允许网页静默读取其他网站或桌面应用窗口。标签页可由扩展直采；桌面应用 / 系统音频至少需要一次共享授权，或改用「立体声混音」虚拟输入走麦克风模式。
